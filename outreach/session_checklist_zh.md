**总时长：** 约 75–90 分钟。**目标：** 先测原版 Whisper 能听懂她多少，再让 CoHear 学习她的声音，最后用同样的句子再测一次。

## 0. 出门前（15 分钟）

- [ ] Mac 上没有正在训练的任务（终端里按 Ctrl+C 停掉）
- [ ] 手机：设置 → Speech model → **Whisper small.en (stock)**，点一次 Listen 确认能用
- [ ] 确认有 **Teach CoHear your voice** 页面
- [ ] 手机至少留 2 GB 空间，Mac 至少 10 GB
- [ ] 手机、Mac 充满电，带 Mac 充电器，两边打开 AirDrop
- [ ] 终端测试：`cd ~/Desktop/Understand && source .venv/bin/activate` 没报错
- [ ] 打印 **2 份同意书**（一份给她留着）和这张表，带笔
- [ ] 给她带水。中风后说话很累

## 1. 到达和准备（5 分钟）

- 安静的房间。关电视、风扇和窗户。
- 她坐舒服。**你拿手机**，离她嘴巴约 30 厘米，每次距离一样。中风常常一只手没力气，别让她拿。
- 坐在她能看到你和句子的位置。字要大，或者让她直接看这张纸读。

## 2. 介绍和同意书（5 分钟）

- **跟她本人说话**，不要只跟家属说，即使家属在帮忙。
- 可以这样说（英文或中文都行）：*"我做了一个能把说的话写成文字的 app。它学了你的声音之后会更准。你的录音只存在我的电脑上，只用来做你的模型，你什么时候想删我就删。随时可以停或者休息。"*
- 慢慢讲同意书，让她提问。家属可以帮她理解，但由她自己决定。
- [ ] 同意书已签

**要有耐心。** 不要替她把话说完，也不要纠正她的发音。说不出来的词就跳过，这句照样算。有些中风患者还会找词困难（失语症），没关系。

## 3. 训练前测试：原版 Whisper（5–10 分钟）

Speech model = **Whisper small.en (stock)**。点 Listen。每句**只说一遍**，用她平时的速度。看字困难的话，你先读一遍，她跟着说（训练后测试也用同样方式）。记下 app 显示的内容，之后再数对了几个词。

## 4. 让 CoHear 学她的声音（10–20 分钟）

设置 → **Teach CoHear your voice**，输入她的名字（英文/拼音）。

1. [ ] 录 32 句 **Quick start** 短句：点录音 → 她说 → 点停 → Keep。看字困难就先点 **Hear it** 或你读一遍，她跟着说
2. [ ] 加 3–5 句**她自己常说的话**：家人名字、每天会说的话（如 "I need my medicine"）
3. [ ] 如果她还有精力，在 "Keep improving" 里多录几段。录越多越好，训练时间几乎不增加
4. [ ] **绝对不要加 B 组句子**，它们必须保持"没听过"，测试才公平

**遇到问题：**

- **提示 "Too long"：** 每段最长 30 秒。她读太久的话，把那段分成两半，各自加成一句。
- **读得很不顺：** 点 Redo。小错误没关系，保留就好，那就是她真实的声音。
- **她累了：** 休息。短一点比累坏好。

## 5. 训练她的模型（约 20–30 分钟）

1. Teach 页面 → **Export recordings** → AirDrop 到 Mac
2. Mac 终端（NAME 换成她名字的小写拼音）：

```
cd ~/Desktop/Understand && source .venv/bin/activate
caffeinate -i bash scripts/build_personal_model.sh NAME \
  ~/Downloads/CoHear-voice-NAME-*.zip --skip-eval
```

3. **等待时：** 休息聊天，趁她还有精神先问第 7 部分的反馈问题。
4. 显示 **Done**，并且有 **"deleted private repo"**（没有的话去 huggingface.co 手动删）后：
   把 `models/whisperkit_personal/user_NAME/PersonalModel-user_NAME.zip` AirDrop 到手机 → 存到"文件" → 点 zip 解压
5. CoHear → 设置 → Teach CoHear your voice → **Install personal model** → 选 `PersonalModel` 文件夹
6. 设置 → Speech model → **Your voice（她的名字）**

开始：______   结束：______

**如果训练失败：** 截图报错，谢谢她，改天再做训练后测试。录音都存着，不会丢。

## 7. 她的反馈（5 分钟，可以用中文问）

- 录音舒服吗？太长吗？
- 字够大、看得清吗？
- 第二次感觉有没有不一样？
- 平时什么时候会用得上？（看医生、打电话、和家人说话）
- 有没有看不懂的地方？
- 也问家属：*你们平时听懂她说话难吗？什么时候最难？*
